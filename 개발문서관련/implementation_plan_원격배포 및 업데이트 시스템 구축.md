# [원격 배포 및 업데이트 시스템 구축]

현재 개발된 챗봇을 다른 컴퓨터(192.168.0.103)에 배포할 수 있는 클린 버전을 만들고, 추후 코드가 수정되었을 때 원격으로 패치(업데이트)할 수 있는 아키텍처를 구축합니다.

## User Review Required

> [!IMPORTANT]
> 인공지능 라이브러리(Langchain, ChromaDB 등)는 `PyInstaller`를 이용해 하나의 `.exe` 파일로 묶을 경우 용량이 수 GB에 달하고 알 수 없는 오류가 빈번하게 발생합니다. 
> 따라서 **소스 코드와 파이썬 환경을 그대로 복사하는 방식(ZIP 압축 배포)**이 가장 안정적이고 속도가 빠릅니다. 아래 제안하는 원격 업데이트 방식이 마음에 드시는지 확인 부탁드립니다.

## Proposed Changes

### 1단계: 첫 배포용 클린 버전 생성 (지금 즉시 진행할 내용)
타겟 PC에 처음 설치할 때 사용할 수 있는 **배포용 압축 파일(`ChatBot_Deploy.zip`)**을 자동으로 만들어주는 스크립트를 작성합니다.
- 용량을 차지하는 불필요한 파일(`.venv`, `__pycache__`, 임시 DB 파일 등)을 제외하고 압축합니다.
- 타겟 PC에서 더블 클릭 한 번으로 파이썬 라이브러리를 설치할 수 있는 `install.bat` 파일을 함께 만듭니다.

### 2단계: 원격 자동 업데이트(Patch) 프로그램 개발 (승인 후 진행)
추후 코드가 변경되었을 때, 개발자 PC에서 버튼 하나만 누르면 타겟 PC(192.168.0.103)에 코드가 덮어씌워지고 서버가 재시작되는 시스템을 만듭니다.

1. **타겟 PC용 업데이터 서비스 (`updater_service.py`)**
   - 타겟 PC에서 항상 백그라운드로 실행되며(포트 8088), 개발자 PC의 패치 신호를 기다립니다.
   - 패치 파일(ZIP)을 수신하면 챗봇 서버를 잠시 끄고, 압축을 풀어 코드를 덮어쓴 뒤 다시 챗봇 서버를 켭니다.
2. **개발자 PC용 원격 패처 (`send_patch.bat`)**
   - 개발자 PC에서 수정한 코드만 ZIP으로 압축하여 타겟 PC(192.168.0.103:8088)로 전송하는 스크립트입니다.

## Verification Plan

### 수동 검증
1. 생성된 `ChatBot_Deploy.zip` 파일 내부에 불필요한 파일이 없는지 확인합니다.
2. 타겟 PC에 ZIP 파일을 옮겨 압축을 풀고 `install.bat`과 `run.bat`이 정상 작동하는지 확인합니다.
3. 원격 업데이트 데모를 위해 로컬에서 업데이터를 실행하고 패치 전송이 성공하여 서버가 재시작되는지 확인합니다.

# 동서대 IC 키오스크(RAG) 기능 연동 완료

일반 챗봇이 아닌 **'동서대 IC 전용 키오스크'**로 동작하기 위한 핵심 기능들의 개발을 모두 완료했습니다.

## 주요 구현 내용

### 1. 지식 베이스(DB) 구축 및 RAG 파이프라인
- **데이터 폴더 생성:** `backend/data/` 폴더가 생성되었습니다. 이 폴더에 `.txt` 파일이나 `.pdf` 파일을 넣어두면 챗봇이 해당 문서를 읽을 수 있습니다.
- **웹사이트 크롤링 추가:** `backend/data/urls.txt` 파일에 웹페이지 주소(URL)를 한 줄에 하나씩 입력해 두면, 자동으로 해당 웹페이지에 접속하여 내용을 긁어와 학습합니다.
- **학습 스크립트 작성 (`ingest.py`):** 폴더 내의 문서와 웹페이지 텍스트를 잘게 쪼개어 로컬 벡터 데이터베이스(ChromaDB)에 저장합니다. **LangChain의 Indexing API(SQLRecordManager)**를 도입하여, 매번 DB를 밀고 새로 쓰는 것이 아니라 **"바뀐 문서(추가/수정/삭제)만 골라서 똑똑하게 부분 업데이트(Incremental Update)"** 하도록 최적화되었습니다.
- **검색 증강 생성(RAG) 연동 (`llm.py`):** 사용자가 질문을 하면, 챗봇이 대답하기 전에 먼저 ChromaDB를 검색하여 가장 관련된 문서를 찾고 이를 프롬프트에 주입하여 답변하도록 개조되었습니다. 

### 2. 키오스크 전용 프론트엔드 (UI/UX)
- **자주 묻는 질문(Quick Buttons):** 채팅창 바로 위에 터치하여 즉각 질문할 수 있는 4개의 퀵 버튼("비자 연장 절차 알려줘" 등)을 추가했습니다. 키보드 타이핑 없이도 주요 정보를 얻을 수 있습니다.
- **자동 초기화 (Idle Reset):** 화면 터치, 마우스 이동 등 아무런 조작 없이 **60초**가 지나면, 현재 대화를 모두 지우고 초기 인사말 화면으로 자동 리셋됩니다. 키오스크 환경에 필수적인 기능입니다.

## 확인 방법 (테스트)
1. **서버 재시작:** 파이썬 패키지가 추가되었고 백엔드 코드가 변경되었으므로 터미널에서 기존 서버를 끄고(`Ctrl + C`) 다시 켜주세요. (`uvicorn main:app --reload`)
2. **새로고침:** 브라우저에서 **F5**를 눌러 새로고침합니다.
3. **퀵 버튼 테스트:** 대화창 위의 퀵 버튼 중 "비자 연장 절차 알려줘"를 클릭해 보세요. 챗봇이 기본 지식이 아닌, 제가 넣어둔 가이드 내용("수수료 60,000원", "재학증명서 필요" 등)을 바탕으로 대답할 것입니다.
4. **리셋 테스트:** 답변을 다 들은 후 마우스를 건드리지 않고 60초간 가만히 놔둬 보세요. 화면이 깔끔하게 지워지고 인사말이 다시 나타납니다.

> [!TIP]
> **새로운 정보 학습하기:** 
> 앞으로 동서대 관련 새로운 문서가 생기면 `backend/data/` 폴더에 파일을 넣거나, `urls.txt`에 웹페이지 주소를 추가하고 터미널에서 `update_knowledge.bat` 명령어만 한 번 실행해 주시면 챗봇이 즉시 똑똑해집니다!

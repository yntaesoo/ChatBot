# 챗봇 배포 및 원격 업데이트 가이드

다른 컴퓨터(타겟 PC)에 챗봇을 설치하고, 추후 개발자 PC에서 수정한 코드를 원격으로 손쉽게 업데이트하는 방법을 안내합니다.

## 1. 타겟 PC (192.168.0.103) 초기 설치 방법

방금 생성된 **`ChatBot_Deploy.zip`** 파일을 USB나 공유 폴더를 통해 타겟 PC로 복사합니다.

1. 타겟 PC에서 `ChatBot_Deploy.zip`의 압축을 원하시는 폴더에 풉니다.
2. 타겟 PC에 **Python 3.10 이상**이 설치되어 있는지 확인합니다. (없다면 파이썬 공식 홈페이지에서 설치)
3. 압축을 푼 폴더 안의 **`install.bat`** 파일을 더블 클릭하여 실행합니다.
   - 자동으로 가상 환경(`.venv`)을 만들고 필요한 AI 라이브러리들을 설치합니다.
   - `backend/.env` 파일이 없다면 자동으로 뼈대 파일을 만들어 줍니다. 설치 후 `.env` 파일을 열어 `OPENAI_API_KEY`를 반드시 입력해야 합니다.
4. 설치가 끝나면 **`run.bat`**을 실행하여 챗봇 서버가 정상 작동하는지 확인합니다.

---

## 2. 원격 업데이트(Patch) 준비

원격으로 업데이트를 받으려면, **타겟 PC에서 수신 대기 프로그램이 항상 켜져 있어야 합니다.**

> [!IMPORTANT]
> 타겟 PC에서 **`run_updater.bat`**을 더블 클릭하여 실행해 두세요.
> (까만색 콘솔 창에 `원격 자동 업데이트 서비스 가동 중... 포트: 8088` 이라는 메시지가 떠 있어야 정상입니다.)

---

## 3. 개발자 PC에서 원격으로 패치 쏘기

개발자 PC(현재 코딩을 하고 계신 PC)에서 코드를 수정한 뒤 타겟 PC로 덮어씌우는 방법입니다.

1. 프론트엔드나 백엔드 코드를 자유롭게 수정합니다.
2. 현재 폴더에 있는 **`send_patch.bat`** 파일을 더블 클릭합니다.
3. 스크립트가 다음 작업을 자동으로 수행합니다:
   - 수정된 최신 코드를 즉시 `ChatBot_Deploy.zip`으로 압축합니다.
   - IP `192.168.0.103`의 8088 포트로 ZIP 파일을 전송합니다.
4. **결과 확인**:
   - 타겟 PC는 패치 파일을 받자마자 실행 중이던 기존 챗봇 서버(`run.bat`)를 강제로 끕니다.
   - 받은 압축 파일을 풀어 코드를 최신화합니다.
   - 챗봇 서버(`run.bat`)를 새로운 창에서 자동으로 다시 시작합니다!

> [!TIP]
> 만약 타겟 PC의 IP 주소가 변경된다면, 개발자 PC의 `send_patch.py` 파일을 열어 `TARGET_IP = "192.168.0.103"` 부분을 수정해 주시면 됩니다.
